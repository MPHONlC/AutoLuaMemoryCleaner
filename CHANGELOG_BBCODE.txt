[SIZE="2"][b][COLOR="RoyalBlue"]Memory Cleanup:[/COLOR][/b][/SIZE]
[LIST]
[*] Automatic cleanups are skipped when Lua memory grew less than the new [COLOR="Lime"]Min. Growth Since Last Cleanup[/COLOR] sliders allow [COLOR="Gray"][i]([COLOR="Orange"]2 MB[/COLOR] or [COLOR="Orange"]5%[/COLOR] by default)[/i][/COLOR], in every cleanup method. A line under the sliders shows how much growth the next cleanup needs.
[*] Entering combat stops a Background cleanup, and it finishes after combat.
[*] When memory is under the threshold, [COLOR="#00FFFF"]ALC[/COLOR] still runs a Background cleanup once per [COLOR="Lime"]Lua Cleanup Delay[/COLOR] to catch garbage [COLOR="Gray"][i](not in combat)[/i][/COLOR], once Lua memory has grown by the [COLOR="Lime"]Min. Growth Since Last Cleanup[/COLOR] sliders [COLOR="Gray"][i]([COLOR="Orange"]2 MB[/COLOR] or [COLOR="Orange"]5%[/COLOR] by default)[/i][/COLOR]. It shows in chat and as an announcement, marked [COLOR="Lime"]Garbage Check[/COLOR], only with the new [COLOR="Lime"]Garbage Check CSA & Chat Logs[/COLOR] on [COLOR="Gray"][i](off by default)[/i][/COLOR].
[*] [COLOR="Lime"]Added[/COLOR] [COLOR="Lime"]Garbage Check Ignores Min. Growth[/COLOR] [COLOR="Gray"][i](off by default)[/i][/COLOR]: with it on, the garbage check runs every [COLOR="Lime"]Lua Cleanup Delay[/COLOR] without waiting for the Min. Growth sliders.
[/LIST]

[SIZE="2"][b][COLOR="RoyalBlue"]Low Memory Protection:[/COLOR][/b][/SIZE]
[LIST]
[*] On [COLOR="#FF69B4"]console[/COLOR], when add-on memory reaches [COLOR="Orange"]70 MB[/COLOR], where the game warns that it is low, [COLOR="#00FFFF"]ALC[/COLOR] now cleans in small steps every frame until it is back under [COLOR="Orange"]65 MB[/COLOR] [COLOR="Gray"][i](Before, it ran a single cleanup when the game warned: a [COLOR="Lime"]Deep Clean[/COLOR] with Automatic, otherwise the method you picked)[/i][/COLOR], in every cleanup method. It ignores the threshold, the minimum growth and the cleanup delay while it does, uses about [COLOR="Orange"]2 ms[/COLOR] of each frame [COLOR="Gray"][i](up to [COLOR="Orange"]6 ms[/COLOR] as memory nears [COLOR="Orange"]90 MB[/COLOR], never more than the game leaves free for add-ons)[/i][/COLOR], and keeps going in combat. Above [COLOR="Orange"]80 MB[/COLOR], when the small steps cannot bring memory down, it also runs a [COLOR="Lime"]Deep Clean[/COLOR], at most every [COLOR="Orange"]5 seconds[/COLOR]. [COLOR="#00FFFF"]ALC[/COLOR] uses [COLOR="#FF69B4"]LibAPH[/COLOR]'s low-memory rescue, so every add-on that starts one shares a single rescue.
[*] [COLOR="Lime"]Added[/COLOR] [COLOR="Lime"]Reload When Add-On Memory Is Almost Full[/COLOR] [COLOR="Gray"][i]([COLOR="#FF69B4"]console[/COLOR], off by default)[/i][/COLOR]. The game turns add-ons off at about [COLOR="Orange"]90 MB[/COLOR] of add-on memory, so if it stays above [COLOR="Orange"]85 MB[/COLOR] for [COLOR="Orange"]10 seconds[/COLOR] [COLOR="#00FFFF"]ALC[/COLOR] asks whether to reload the UI [COLOR="Gray"][i]([COLOR="Orange"]5 seconds[/COLOR] to answer)[/i][/COLOR], and at [COLOR="Orange"]88.5 MB[/COLOR], or sooner when memory is climbing fast enough to reach [COLOR="Orange"]89.5 MB[/COLOR] within a second, it saves every add-on's data and reloads right away. If the reload does not bring it below [COLOR="Orange"]85 MB[/COLOR], [COLOR="#00FFFF"]ALC[/COLOR] asks you to restart the game.
[*] [COLOR="Lime"]Added[/COLOR] [COLOR="Lime"]Low Memory CSA & Chat Logs[/COLOR] [COLOR="Gray"][i]([COLOR="#FF69B4"]console[/COLOR], off by default)[/i][/COLOR]. With it on, each low-memory step [COLOR="Gray"][i](cleaning started, memory back down, almost full, reloading, reloaded)[/i][/COLOR] shows a short announcement and the full message in chat, whatever [COLOR="Lime"]Center Screen Announcements[/COLOR] and Chat Logs are set to.
[/LIST]

[SIZE="2"][b][COLOR="RoyalBlue"]Memory Pool Cleanup:[/COLOR][/b][/SIZE]
[LIST]
[*] [COLOR="Lime"]Auto Pool Cleanup After Travel[/COLOR] is now [COLOR="Lime"]Reload After Loading Screen When Memory Is Bloated[/COLOR], on [COLOR="#FF69B4"]PC[/COLOR] and [COLOR="#FF69B4"]console[/COLOR], off by default. After a loading screen, if memory is still above the threshold after a full cleanup, [COLOR="#00FFFF"]ALC[/COLOR] saves every add-on's data and reloads the UI [COLOR="Gray"][i]([COLOR="Lime"]Console Pool Threshold[/COLOR] on [COLOR="#FF69B4"]console[/COLOR], the new [COLOR="Lime"]PC Reload Threshold[/COLOR] (MB) on [COLOR="#FF69B4"]PC[/COLOR], [COLOR="Orange"]500 MB[/COLOR] by default)[/i][/COLOR]. It never reloads in trials, arenas, group dungeons, the Infinite Archive, battlegrounds, Cyrodiil, Imperial City or duels, or while queued for an activity.
[*] [COLOR="Lime"]Added[/COLOR] [COLOR="Lime"]Minimum Time Between Reloads[/COLOR] [COLOR="Gray"][i](Minutes)[/i][/COLOR], 10 to 180 [COLOR="Gray"][i](60 by default)[/i][/COLOR], for [COLOR="Lime"]Reload After Loading Screen When Memory Is Bloated[/COLOR].
[*] [COLOR="Lime"]Added[/COLOR] [COLOR="Lime"]Reload When AFK[/COLOR] [COLOR="Gray"][i]([COLOR="#FF69B4"]PC[/COLOR] and [COLOR="#FF69B4"]console[/COLOR], off by default)[/i][/COLOR] with [COLOR="Lime"]AFK Time Before Reload[/COLOR] [COLOR="Gray"][i](Minutes)[/i][/COLOR], 3 to 15 [COLOR="Gray"][i](10 by default)[/i][/COLOR]. After that long standing still on the HUD, [COLOR="#00FFFF"]ALC[/COLOR] saves every add-on's data and reloads the UI, then waits until you move before it can do it again. Moving, opening a menu or combat starts the time over, and it never reloads in the activities above.
[/LIST]
